# AguMaster — A 股 AI 实时诊断工具

在交易时段按所选档位自动拉取自选行情，自动记录近段走势（最长 20 个交易日），调用大模型生成短线诊断、支撑/压力位与操作建议（建仓/短期/波段/长期），支持投资风格（激进/中立/保守）与投资周期（短线/波段/长期，长期模式建议跨日稳定）及前瞻性走势分析；**诊断参照盘内 + 盘外综合**（隔夜美股/费半·英伟达·台积电·美光/恒生/三星/SK海力士等风向标 + 今开价，盘外为辅助权重）；内置模拟盘绩效闭环（净值曲线/胜率/回撤/归因），价格突破关键位时桌面弹窗提醒。

## 桌面版（推荐，Win11）

功能最完整：完整看板 + 悬浮窗 + 分组侧边栏 + 组合追踪 + 桌面通知预警。

### 快速启动

```bat
start-desktop.bat
```

首次自动安装依赖，后台启动 Vite，打开 Electron（完整看板 + 悬浮窗）。

### 打包安装包

```bat
build-installer.bat
```

输出 `desktop/release/staging/AguMaster-{version}-win-x64-setup.exe`，含 Electron 运行时与前端静态资源，目标电脑无需 Node.js。安装后配置保存在 `%APPDATA%/AguMaster/agu/`。

### 主要操作

| 操作 | 说明 |
|------|------|
| 添加自选 | 展开配置 → 输入代码（如 `600519`、`hk00700`）→ 添加 |
| 自动刷新 | 选择刷新档位（5/15/30/60 分钟），交易时段自动对齐触发 |
| 手动刷新 | 点击「立即刷新」，全池 20 只同时拉行情 + AI 诊断 |
| 悬浮窗 | 配置区勾选 1–5 只钉选到桌面半透明小窗 |
| 分组管理 | 左侧侧边栏 → `+ 新建分组`，可重命名/删除，显示组内数量；卡片下拉框选择归属分组 |
| 刷新模式 | 每张卡片的 ◌/⚡/⚡⚡ 按钮切换：关闭 / 正常 / 超频 |
| 超频刷新 | ⚡⚡ 模式——交易时段内每 30s 拉行情 + 关键位预警，上限 5 只，需先配置**持仓成本 + 关键位** |
| 持仓管理 | 卡片上「+ 添加持仓」输入数量与成本价；已配置持仓的卡片显示浮动盈亏，可编辑/清除 |
| 关键位 | AI 自动给出支撑/压力位，也可手动添加自定义警戒价（卡片上 `+` 按钮） |
| 操作建议 | **无持仓（观望）**：显示建仓建议（锚定关键位）；**有持仓**：显示波段建议 + 短期建议（结合盈亏给仓位动作）；**波段建议日内稳定**（每天更新一次，关键位显著变化时盘中更新）；配置已实现盈亏后 AI 战略随盈亏切换（亏→回本/止损，盈→扩利/锁盈） |
| 半自动采纳 | 建议行尾点「采纳」→ 弹窗确认：AI 只给价位与方向，**数量由你填写**（卖出不超持仓、买入不超可用资金实时校验）；卖出提供 1/3、1/2、全部比例快捷；成交自动记账并计入绩效归因 |
| 投资周期 | 配置选择 **短线 / 波段 / 长期**；长期模式只显示「长期策略」一行（中期趋势判断 + 持有/减仓动作 + 离场条件），**建议跨日稳定**——看涨就不管今天的涨跌继续持有，仅关键位实质变化或价格穿越时更新；注入近 20 日历史 |
| 盘外参照 | 诊断自动综合盘外风向标：美股大盘/中概金龙、费半·英伟达·台积电·美光·苹果·特斯拉（板块风向）、恒生·三星·SK海力士（亚太实时）+ 今开价；与个股量价背离时明确指出，建议仍锚定个股关键位；拉取失败自动省略 |
| 组合追踪 | 左侧侧边栏 `+ 新建组合`（可选行业板块），添加证券+权重 → 组合卡片展示加权涨跌（含板块补偿） |
| 绩效面板 | 侧边栏「绩效」→ 净值曲线（vs 沪深300）+ 总收益/胜率/最大回撤/盈亏比 + 建议归因表；模拟成交含 A股手续费（ETF 免印花税） |
| 桌面通知 | 配置区可开关：价格突破 / 高风险信号 / API 异常 / 行情异常 |
| 导出备份 | 配置区「导出用户数据备份」 |

### 配置面板

点击「展开配置」可设置：

- **API 连接**：Base URL、API Key、模型名称
- **投资风格**：激进 / 中立 / 保守（影响 AI 减仓阈值与建议倾向）
- **投资周期**：短线 / 波段 / 长期（长期=只给中期持有/减仓策略与离场条件，跨日稳定、忽略日内波动）
- **刷新档位**：下拉选择 5 / 15 / 30 / 60 分钟
- **桌面悬浮窗**：勾选钉选证券、调整透明度、始终置顶
- **桌面通知预警**：独立开关各种通知类型

## H5 版（浏览器）

```bat
start.bat
```

启动后访问 `http://localhost:5180`，手机/平板/桌面浏览器均可使用。功能为桌面版子集（无悬浮窗、无桌面通知）。

## 个人配置

在页面「展开配置」中填写 API Key、添加自选、创建分组、选择投资风格。配置保存在本地存储（桌面版同步写入 `%APPDATA%/AguMaster/agu/config.json`），不会上传到任何服务器。

## 环境要求

- **Windows 11**（桌面版） / 任意现代浏览器（H5 版）
- **Node.js 18+**（一键脚本可自动安装）
